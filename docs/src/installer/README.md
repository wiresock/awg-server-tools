# VPN installer (`amneziawg-install.sh`)

`amneziawg-install.sh` installs and manages an AmneziaWG VPN server on Linux.
New installations use **AmneziaWG 2.0** by default (kernel backend). An
experimental **BoringTun** userspace backend is available on fresh installs
only; see [BoringTun](../boringtun/README.md).

## Topics

- [Non-interactive install](non-interactive.md)
- [Managing clients](clients.md)
- [AWG 3.0 / 3.1 mode](awg3.md)
- [Ubuntu 26.04 PPA](ubuntu-26.04-ppa.md)

Re-run `sudo ./amneziawg-install.sh` after installation to manage clients
interactively.
